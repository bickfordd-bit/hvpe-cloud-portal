# AGENTS.md — Bickford Specialists

All specialists are workers under the Bickford Constitution.

## Specialists (examples)
- code: implements changes + tests
- infra: CI/CD, deployments, permissions
- mobile: iOS/Android builds, store pipeline
- docs: docs/legal/pilot artifacts
- security: secrets, scanning, policy

## Non-negotiables
- Same output format (Intent → Contract → Proof → Result → Ledger)
- Fail-closed if proof is missing
- No “done” without verification commands + artifacts
