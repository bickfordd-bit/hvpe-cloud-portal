## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- OpenAI API Key

### Environment Setup
```bash
# Set your OpenAI API key
export OPENAI_API_KEY="your-api-key-here"
# OR
export HVPE_OPENAI_API_KEY="your-api-key-here"
```

### Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Access Bickford at: http://localhost:3000/bickford
```

### Production Deployment

#### Option 1: Vercel (Recommended)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
npm run deploy:vercel
```

#### Option 2: Docker
```bash
# Build and run with Docker
./deploy.sh docker
```

#### Option 3: Manual
```bash
# Build for production
npm run build

# Start production server
npm start
```
