# BICK Ledger

This directory contains the immutable ledger of BICK (Bickford Intent-Cognitive-Knowledge) measurements for this repository.

## Files

### Snapshots (Generated)
- `snapshot-*.json`: Timestamped snapshots of BICK calculations
  - Contains: signals (work items, cognitive load), computed results, timestamp
  - Format: `snapshot-{ISO8601-timestamp}.json`
  - Generated by: `bick score`, `bick report`, `bick tick`

### Reports (Generated)
- `BICK_REPORT.md`: Latest human-readable BICK report
  - Generated by: `bick report`
  - Contains: BICK score, component breakdown, next-best-actions

### Actions (Generated)
- `NEXT_BEST_ACTIONS.json`: Latest improvement recommendations
  - Generated by: `bick tick`
  - Contains: timestamped list of actions to increase BICK

## Usage

These files are automatically generated. Do not edit manually.

To generate new measurements:
```bash
bick score    # Compute BICK (JSON output)
bick report   # Generate human-readable report
bick tick     # Get next-best-actions
```

## Snapshots are append-only

The snapshot files form an immutable ledger showing BICK evolution over time. They are:
- Never modified after creation
- Used for historical analysis and trend tracking
- Automatically generated on each BICK run

## Git tracking

Snapshot and report files are `.gitignore`d to keep the repo clean. The ledger exists locally and in CI artifacts but is not committed to version control.
