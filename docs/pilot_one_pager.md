### Week 1: Onboarding
- [ ] **Day 1**: Kickoff call (60 min) – Objectives, access provisioning, demo

- [ ] **Day 5**: First RFP analysis – Customer provides 2 active RFPs for OPTR to process

### Week 2-3: Active Use
- [ ] **Ongoing**: Users analyze 10+ RFPs using OPTR
- [ ] **Mid-Pilot Check-In** (Day 14): Review progress, address blockers, adjust scope if needed
- [ ] **Feedback Collection**: Users submit feedback via in-app survey or Slack

### Week 4: Evaluation
- [ ] **Day 25**: Metrics review – Compare baseline vs. pilot results

## Risk Assessment & Mitigation

### Risks
1. **Low User Engagement**  
   - **Mitigation**: Weekly reminders, gamification (leaderboard for most RFPs analyzed), direct manager involvement

2. **Data Quality Issues** (RFPs hard to parse or missing)  
   - **Mitigation**: Pre-screen RFPs with customer before pilot; manual fallback for edge cases

3. **Feature Gaps Discovered**  
   - **Mitigation**: Document gaps for roadmap prioritization; offer manual workarounds during pilot

4. **Integration Challenges** (e.g., CRM, internal tools)  
   - **Mitigation**: Limit pilot scope to standalone use; plan integrations for post-pilot phase

### Assumptions
- Customer has stable internet access and modern browsers (Chrome, Edge, Safari)
- RFPs are in PDF, DOCX, or text format (no scanned images without OCR)
- Users have 2+ hours per week to dedicate to pilot activities
