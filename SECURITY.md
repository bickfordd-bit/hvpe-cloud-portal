## Security and Vulnerability Reporting

Thank you for reviewing the security of this project. If you discover a security
vulnerability that affects this repository, please follow the responsible
disclosure steps below.

1. Do NOT create a public issue describing the vulnerability.
2. Send an email to security@your-domain.example with the subject line:
   "[SECURITY] hvpe-cloud-portal vulnerability report".
3. Include:
   - Affected component / file paths
   - Steps to reproduce or a proof-of-concept
   - Impact assessment and suggested mitigations (if possible)
4. We will acknowledge receipt within 48 hours and coordinate a fix and disclosure
   timeline.

If you prefer, you may also provide an encrypted message using the project's
PGP key (available from security@your-domain.example) and include your contact
details for coordination.

Notes:
- Do not exploit any vulnerability beyond what's necessary to demonstrate it.
- We aim to triage and patch critical vulnerabilities within 7 business days.
